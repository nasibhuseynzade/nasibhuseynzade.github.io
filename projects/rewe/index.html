About this project

The REWE online shop publishes thousands of prices every day. This project collects daily snapshots for two regions, Bavaria and Schleswig-Holstein, from November 2023 to September 2025: 970 files and about 20 million rows. Raw CSVs are kept untouched, converted to Parquet, and modelled with dbt on DuckDB into a medallion structure, from cleaned daily prices to price intervals, monthly prices and ready-made analyses.

Shop data is messy. Products disappear from a page for a day, pack sizes contain typos like 1000kg instead of 1000g, and the printed price per kilo sometimes contradicts the pack size. Each of these cases is handled in the models and covered by data tests, so that a price jump or a shrinkflation case on this page is real and not a parsing error.

The assistant on top does not guess. It translates a question into calls to eleven parameterised tools, or into a single read-only SQL query that passes a strict guard, and answers only from the results. An evaluation set of 42 questions in three languages measures how often each model picks the right tool and quotes the right numbers.

Key features

  1. Medallion pipeline on 20 million rows

    Daily CSV snapshots become Parquet, then dbt models in DuckDB: cleaned daily prices, price intervals, a chained price index and analysis tables, guarded by 37 data tests.

  2. Data quality you can audit

    Gaps-and-islands price intervals, detection of incomplete snapshots, and pack sizes reconciled against the printed unit price, so source typos don't become fake price jumps.

  3. An LLM with tools, not guesses

    The model chooses among parameterised queries; free SQL runs only through a guard that allows a single read-only SELECT on the analysis tables, with row and time limits.

  4. Measured, with fallbacks

    A 42-question evaluation scores tool choice and numbers per model. If one provider is down or rate-limited, the next one answers: Cloudflare Workers AI, Groq, Gemini.
